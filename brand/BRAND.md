# Mindful brand kit

## Logo
| File | Use it for |
|---|---|
| `logo/mindful-original.svg` | Exact trace of the hand-drawn logo |
| `logo/mindful-primary.svg` | Main logo (even line weight) |
| `logo/mindful-solid.svg` | Small sizes, under 120px wide |
| `logo/mindful-app-icon.svg` | App icon, favicon, social avatar |
| `logo/mindfull-*-concept.svg` | Two-L "Mindfull" concepts (second L copied from the drawing) |

The logo is one color: ink blue. Never put it on a busy photo.

## Colors (60 / 30 / 10)
| Name | Hex | Use |
|---|---|---|
| Paper | `#F6F8FF` | Backgrounds (60%) |
| Ink blue | `#2F4FD8` | Logo, headlines, links (30%) |
| Impact coral | `#FF6B3D` | Verified badges only, never text on it (10%) |
| Deep coral | `#C8431A` | Buttons with white text (4.9:1 contrast) |
| Night | `#0F1730` | Dark mode background |
| Light blue | `#8FA6FF` | Logo and headlines in dark mode |
| Slate | `#3A4250` | Body text |

## Fonts
- Headlines: **Fredoka** 600, letter-spacing -0.02em on large sizes
- Body: **Nunito** 400/700
- Big moments only: **Rubik Bubbles**

## Voice
- Shows, doesn't claim: "See 12 live demos", not "Top talent"
- Warm, like the bubble letters
- Plain words: "Find a developer", not "Leverage our talent network"

Tagline: **Proof, not promises.**

## Open decisions
- Name: Mindful vs Mindfull (two-L version needs a new drawing to trace)
- 5-second legibility test of the hand-drawn "nd"

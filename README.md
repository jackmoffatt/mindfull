# Mindful

A marketplace where businesses, agencies and side-hustlers hire web developers who show their work: live demos, verified client reviews and real delivery stats, with no cold calls.

**Proof, not promises.**

## What's here
| Folder | What it is |
|---|---|
| `site/index.html` | Landing page prototype (open it in a browser) |
| `brand/` | Logo files and the brand kit (`BRAND.md`) |
| `docs/idea-map.html` | The idea map: profiles, status levels, money model, name research |
| `.claude/skills/claude-gpt-debate/` | Skill that gets a second opinion from GPT and finds common ground (needs an OpenAI API key) |

## Status
Prototype. The waitlist form is a preview and does not save sign-ups yet.
